# 服务器供应商配置

在 Web 或 iOS 界面的会话侧栏选择「供应商管理」，添加名称、接口协议、基础地址、API Key 和模型 ID。每行填写一个模型 ID；地址使用供应商对应协议的基础地址，例如 OpenAI 兼容接口通常以 `/v1` 结尾，Gemini 通常以 `/v1beta` 结尾。请以供应商的实际接口文档为准。

供应商配置保存在 RCS 数据目录的 `providers.db`。列表不会返回密钥；修改接口地址或协议时必须重新输入密钥。CLI 使用已有的 RCS 凭据获取完整配置，然后直接连接供应商；模型请求不经过 RCS。

在连接了该 RCS 的交互式 CLI 中运行 `/model`，选择「供应商 / 模型」。网页中连接到支持此功能的终端后，也可以从会话设置选择。切换时从服务器重新读取配置；如果读取失败或模型已删除，原选择保持不变。每个 CLI 进程独立选择，正在执行的回合及其子任务使用开始时的配置。切换回现有本地模型时仍使用原有本地配置。

CLI 需要配置 `CLAUDE_BRIDGE_BASE_URL` 和 `CLAUDE_BRIDGE_OAUTH_TOKEN`。由设备 Spawner 启动且已连接 RCS 的终端会继承这些设置；手动终端需要通过现有启动器配置或自行设置它们。旧版终端不会出现服务器供应商选项，需要更新 CLI 并重新打开终端。

服务器当前支持 Anthropic、OpenAI 兼容、Gemini 和 Grok 协议。兼容接口的具体模型能力由供应商实现，配置成功不代表所有模型都支持图片、工具调用或思考模式。

**部署提醒：**密钥需要从 RCS 传给 CLI。使用 HTTP 时该传输未加密；如果服务器没有访问控制，能访问管理界面的人也能更改供应商配置。请根据部署环境控制访问范围并保护 RCS 凭据和数据目录。
